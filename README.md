крч сделал гроккинг на сложении по модулю 113, слева модели с weight decay, справа без него, по горизонтали обучение от 0 до 20 000 шагов, по вертикали точность от 0 до 100%, цвета это три разных запуска, пунктир это обучающие примеры, сплошные линии это новые

модели быстро зазубрили обучение, но слева через несколько тысяч шагов начали решать почти все новые примеры, а справа остались примерно на 4-7%, вот этот поздний скачок обобщения и есть гроккинг
